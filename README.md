### 🚀 Flagship Engineering Projects

#### ✈️ [Airline Booking Distributed System (High-Concurrency Architecture)](https://github.com/Shimbhu77)
> High-concurrency, event-driven airline reservation platform engineered across 6 autonomous microservices.
- **Orchestrated Saga Pattern**: Built a 4-step workflow (Reserve  → Authorize  → Capture → Confirm) with automated compensating transactions for cross-service eventual consistency.
- **Transactional Outbox Pattern**: Eliminated dual-write inconsistencies between PostgreSQL and Kafka using atomic DB outbox tables and monotonic KRaft event relay.
- **High-Contention Concurrency**: Enforced zero-double-booking seat invariants using atomic conditional SQL updates and partial unique indexes without distributed lock contention.
- **Fault Containment**: Engineered durable wait-and-replay idempotency tables, Resilience4j circuit breakers with exponential jitter, and OpenTelemetry W3C distributed tracing.
- **Stack**: `Java 21` • `Spring Boot 3` • `Apache Kafka (KRaft)` • `PostgreSQL 17` • `Docker` • `Resilience4j`

#### 🤖 [AI-Powered Jira Automation Agent](https://github.com/Shimbhu77)
> Intelligent enterprise sprint assistant automating ticket lifecycles and natural-language queries.
- Built with **Spring AI**, **RAG over PGVector (PostgreSQL 17)**, and structured **Tool Calling**.
- Automates Jira Cloud REST API workflows, sprint state transitions, and conversational JQL querying.
- Integrated chat memory and vector similarity search to retrieve internal technical runbooks.
- **Stack**: `Java` • `Spring AI` • `PGVector` • `PostgreSQL` • `REST APIs` • `Docker`
